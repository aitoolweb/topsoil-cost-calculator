# Topsoil Cost Calculator

[Topsoil Cost Calculator](https://topsoilcostcalculator.com/) — Free topsoil calculator: enter area and depth to get cubic yards, tons, bag counts, and an estimated cost for your yard project.

## Official website

**[Topsoil Cost Calculator](https://topsoilcostcalculator.com/)**

## Mini tool (in this repo)

Open [`tools/index.html`](tools/index.html) for a tiny browser helper (Cubic yards helper). It runs locally in your browser and links out to the live site.
